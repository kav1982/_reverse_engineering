激光 · Spell1004

Missile 主动法术 · ID 10041–10043 · hitscan 一帧成线 · speed 是长度不是速度 · 寿命硬编码 0.2s · Lv2+ 穿透转折射

1. 是什么

开火当帧一次性把整条折线算完，线上所有异阵营目标同帧各吃一次伤害。speed=15 是这条折线的总长度预算——首帧读走之后立刻 Speed = 0，实体从此只是个挂 LineRenderer 的壳，活 0.2 秒就销毁。Lv2/3 把「穿透」变成「折射」：撞到单位后不穿过去，而是拐向下一个没打过的敌人。

文案：机制栏 7110041 为空，7110042/3 才写「法术穿透+int1，法术穿透会变为折射效果」。风味文案三段全部能在代码里落地——「笔直施放」= angle=0、「法杖也愿意更快施放法术」= 两个法杖层字段、「瞬间完成攻击」= hitscan。

  • ECS 主路径：Spell1004LaserSystem + Spell1004LaserJob（线生成 + 伤害 + 销毁判定，一个 Job 全包）
  • 完全不进 SpellPhysicsSystemGroup：SpellMoveJob 里没有 Laser 分支
  • Mono Spell1004Laser 为残留轨，见第 8 节
  • 升级买的是暴击率和折射次数，不是伤害
  • CalculateSpellComplexity 记 3 分（与滚球、蝴蝶、霰弹同档）

不要和棱镜核心混淆：LaserBeam = 4014（棱镜核心 / Prism Core）是持续 DPS 型法杖符文，和本文的 Laser = 1004 是两套机制。《雷霆晶石逆向分析.md》曾把 4014 的 ID 误写成 1004 并得出错误结论，见第 7 节。

  • 伤害同帧一次性结算，没有「扫过去」的过程
  • hitList.Contains 去重 → 每个实体最多吃一次
  • 实体位置被搬到折线远端（lineBuffer[0] 是最后插入的点）

  • 不走 SpellMoveJob，没有通用位移

  • 不是持续施法（isKeepCasting=false）

// 墙层过滤器：BelongsTo = 16777216u (bit 24), CollidesWith = 256u (bit 8)
  • 反弹用 Job 自己算的 math.reflect，不是普通弹那套 Unity Physics 碰撞事件
  • IsIgnoreWall 时次数不扣 —— 无视墙壁的激光穿墙且省下所有反弹次数
  • 墙反弹与折射是两条独立计数，同一发里可以各自触发
  • 反弹不重置长度预算（stepVelocity *= wallHit.Fraction 只截断到撞点）→ 反弹再多也射不出总长 15 之外
  • ReboundAddTime（反弹给普通弹的加时）对激光无效，因为激光不读 Duration
  • Rotation 路径根本不调这个函数 → 公转激光无视墙

段数恒为 20 是因为预算与步长同比放大（Speed / (Speed × 0.05) = 20）。副作用：每步最大转角含 Speed 因子，所以加速器让追踪型激光拐得更急。

AI 射程估算比实装多 5：SpellGroupAttackDistanceCalculator L255–257 写的是 5f + speed = 20，实装是 15。那个 5f 是 Mono 时代预制体 maxLength 的遗留（Mono：_remainDistance = maxLength + spellCfg.speed），ECS 简化后没同步改估算式。只影响自动施法法杖 / 队友 AI 的开火距离。

待决：① 穿透→折射未扣减是 bug 还是刻意改动？代码事实确定（ECS 只加不清零，与 Mono 及文案两边都不符），性质未定 —— 需实机验证 [穿Lv3][激光Lv3] 命中数是 7 还是 11。这是优先级最高项。② 坠落落点圆半径为 0 的实际后果（Unity Physics 零半径 OverlapSphere 是否仍返回包含该点的碰撞体？坠落是否通过 FallRadius 给出非零底数？），置信度中。③ float1=4/float2=2 是死字段（置信度高），但「曾是长度和寿命」只是推测。④ FindReflectionTarget 的搜索半径未展开，它决定折射「能拐多远」。⑤ RotationFallRefraction L1283–1350 里 while 后紧跟的 for (j < refractRemain) 疑似死代码，未下结论。⑥ 悬停绊线每帧重扫整条折线，公转激光 37 个点 × 10 秒窗口的性能影响未测。⑦ 多重施法 3002 / 超载散射 3003 / 寻踪 3010 / 自我追踪 3114 / 公转 3009 尚无逆向文档，未做逐一校验。
