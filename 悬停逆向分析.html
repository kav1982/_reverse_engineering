悬停 · Spell3008

Enhance 符文 · ID 30081–30083 · 飞行结束后原地再停 float1 秒 · 独立 HoverDuration，不进 Duration

1. 是什么

插在主动 / 召唤左侧的生命周期符文。飞行段走完后不立刻销毁，在原地锁死再停 float1 秒。不改伤害、半径、速度、蓝耗。

文案：法术结束时会在原地悬停 float1 秒。三级同名，只有秒数不同。

  • 没有 Spell3008*System / Authoring
  • 配置标了 haveEffecforSummonSpell=false，运行时不读
  • SpellHoverDamage* 是部分预制体自带的驻留伤，不是这张卡挂上去的

2. 数值

IDLvfloat1 秒售价可合成

  • 等级不是每级 ×2：2 → 3 → 5
  • 售价每级 ×3（8 / 24 / 72），比伤害强化便宜 1 金
  • float2/3、int1/2/3 全 0，未使用
1×Lv2 = 3s，2×Lv1 = 4s （等级不能互替） 1×Lv3 = 5s，Lv1+Lv2 = 5s （只有这一档碰巧相等） · 合成只省槽

3. 叠加：加算秒数

实际 · Σfloat1

  • 2×Lv1 → 4s
  • 底数从 0 加
  • 自动填槽不自排斥

误解

  • 不是 max(2, 2) = 2
  • 不是并进 Duration
  • 不是一张高级 = 两张低级
SpellShootData.GetSpellHoverDuration多张相加
float num = 0f;
foreach (var slot in EnhanceList)
{
    var cfg = slot.GetFinalConfig();
    if (cfg.abilityType == SpellAbilityType.SpellHover)
        num += cfg.float1;
}
return num;

Mono 同样是 SpellHoverTime += float1。写入 SIP.SpellHoverDuration → HoverDuration，HoverTimer 初始为 0。

GetSpellDuration() 不读悬停。时长强化（3103）只改飞行段。

4. 生命周期：两段计时

飞行中 DurationTimer < Duration 正常移动、正常命中 刚结束 Duration 用尽 Speed = 0，进入悬停 悬停中 HoverTimer < HoverDuration 锁位置，实体还在 悬停结束 HoverTimer >= HoverDuration 销毁 / 缩小 / OnOver / 分裂
SpellSystem.UpdateDuration通用 ECS 路径
if (DurationTimer < Duration.Calculate())
{
    DurationTimer += dt;
    return;
}
Speed = 0f;
if (HoverTimer < HoverDuration)
    HoverTimer += dt;
else
    destroySelf = true;   // 或缩小回收
SpellMoveJob锁位置
if (HoverTimer > 0f && HoverDuration > 0f)
{
    movement.Speed = 0f;
    velocity.Linear = float3.zero;
}

进悬停当帧 HoverTimer 仍是 0。原版靠 UpdateDuration 先把 Speed=0。只抄 MoveJob 条件会滑一帧。

谁不走这条路径

  • IsFallSpell；激光 / 符文锤 / 激光束 / 彼岸刃 / 伞 / 高压水枪 / 戴夫鱼叉
  • 高压水枪、诡雷（非坠落）、巨型泡泡：把秒数折进 Duration，再把 HoverDuration 清零（这段更久，不是停在原地）
  • 持续施法锁：只有冲刺把悬停算进去；分解射线 / 高压 / 龙息不算

回收在第二段之后

  • OnOver / 分裂挂在回收上，不是飞行刚停
  • 命中且穿透耗尽直接销毁，走不到悬停
  • 半命传送仍看 Duration/2，和悬停无关

5. 悬停阶段还打不打

这张卡不出伤。只续命、锁位。出不出伤看法术自己。

情况悬停阶段
普通弹 Enter新走进碰撞盒仍打；已重叠的 Stay 不再结算
DPS / DamageInterval实体还在，计时器通常继续转
奥爆 1008自带 HoverDamageTimer，约每 0.4s 再全范围打一次
SpellHoverDamageData预制体组件，Stay 满 Interval（默认 0.33s）打一圈
命中已死的弹没有实体，无悬停

不要做成「悬停 = 自动 DPS」。碰撞和特效要活过第二段。

6. 摆放：左侧累积

只强化自己右边、同一段里的主动 / 召唤。主槽加不到后槽。

悬弹 → 弹吃 2s
弹悬 → 吃不到
悬奥爆弹 → 两张都吃
悬召唤 → 运行时仍写入（表标无效，但不读）

自动填槽不在自排斥 / 忽略名单里，手摆和自动都可以叠多张。

7. 开发注意事项

计时

  • 不要做成「寿命 +float1」
  • 多张相加，底数从 0
  • 进段当帧锁位置

存活

  • 命中销毁优先于悬停
  • OnOver / 分裂挂在回收上
  • 这张卡不出伤

例外

  • 坠落 / 激光族不走通用路径
  • 部分法术把秒数并进 Duration
  • 「对召唤无效」运行时不读
