落雷阵 · Spell1018 ThunderAura

Missile 主动法术 · ID 10181–10183 · speed=0 原地光环 · isDPS 每 0.25 s 结算 · 单次最多劈 int1 个目标 · 面板 damage 实为「每秒伤害」

1. 是什么

在法杖枪口放下一个完全静止的 5 秒雷雨区（speed=0，玩家不能选点）。每约 0.25 秒结算一次，在 radius 内挑最多 int1 个异阵营目标同时劈。圈内人数不足 int1 时，从 1.5 倍半径的环带随机补人——这就是面板说的「传导」。只劈到 1 个目标时整发伤害 ×float1%。

isDPS = true → DamageInterval = DPSDamageInterval = 0.25 → 单次伤害 = damage × 0.25 → 面板 damage 字段的真实语义是「每目标每秒伤害」 → 面板给伤害数字挂 "(秒伤)" 后缀（文本 14000302） 这是本套文档第一篇 isDPS 法术，持续伤害模型见 md 第 2.3 节。
  • ECS 主路径：Spell1018ThunderAuraSystem 内两个互斥 Job —— Spell1018Job（光环，WithNone<SpellFallTag>）/ Spell1018FallJob（坠落，WithAll<SpellFallTag>）
  • SpellMoveJob.cs 里一处 ThunderAura 都没有，走 Normal_Common，Speed=0 → 不动
  • Mono Spell1018ThunderAura 为残留轨，传导实现与 ECS 完全不同，见第 7 节
  • CalculateSpellComplexity 记 3 分（与滚球、蝴蝶、激光同档）

风味文案「划定一片区域，落雷会攻击区域内的目标，区域外的敌人也可能会被牵连」——后半句准确（1.5 倍环带补位），前半句言过其实：玩家无法划定位置，只能落在枪口。

已核验的性质

  • 查询无任何生命周期条件（不看 DurationTimer / HoverTimer）→ 悬停白送输出的根因
  • Radius.Calculate() 每 tick 现算 → 运行期改半径立刻生效
  • 候选列表每 tick 重建，无命中记忆、无冷却、无去重
  • MakeDamageInfo(costPenetrate: false) → 穿透完全无效

不是这样

  • 不是链式扩散（ECS 补位中心是光环自己）
  • 不是「1 主目标 + int1 次传导」（总共就 int1 个）
  • 不是挑最近的（Random.NextInt 随机补位）
  • 不能打可破坏物（Brittleness 被过滤两次）

3.1 抖动间隔：均值不变，只改节奏

GetRandomDamageInterval = Random(−0.25×0.6, +0.25×0.6) = U(−0.15, +0.15) 每次扣减 = 0.25 + U(−0.15, 0.15) ∈ [0.10, 0.40] E[扣减] = 0.25 恰等于触发阈值 → 长期平均精确 4 次/秒，抖动不改 DPS 5 秒窗口结算次数：均值 20，标准差 √20 × 0.0866/0.25 ≈ 1.55（约 ±8% 一西格玛） float2 的用途是表现层：多个光环同场时打散雷击节拍，它不是伤害系数。

3.3 单目标加伤的陷阱

判定的是本次结算的最终命中数 num，不是「场上敌人数」。 Boss 战里飘进来一只小怪（哪怕在 1.5 倍环带被补进来）： num: 1 → 2 ⇒ Lv3 单体伤害 ×1.6 → ×1.0 = 瞬间掉 37.5% float1 是最后一道乘算，不进 AttributeValue，任何符文都改不了它。 Lv1 的 float1=100 让这条机制在一级不存在 ⇒ Lv1→Lv2 实际单体提升 = 44×1.3 / 22×1.0 = 2.6 倍，高于 damage 字段的 2 倍。

5.3 加速器 3106 / 自动导航 3011 —— Speed=0 的两个后果

加速器 · 静止光环变雷云

  • Calculate() = (0 + float1) × ... = float1
  • Lv1 3 m/s → 5 秒漂 15 m（横穿房间）
  • Lv2 6 → 30 m ／ Lv3 12 → 60 m
  • 落雷阵的价值是区域封锁 → 默认负收益，等级越高越差
  • 佐证：AI 射程算 max(半径, 速度×时长)，策划知道这个组合
  • 配悬停可缓解：duration 用尽后 Speed 被压 0，「推进到位再驻扎」

自动导航 · 完全空转

  • 只把 Type 改成 ChaseEnemy，落到通用 Normal_ChaseTarget
  • num = Speed = 0 ⇒ maxDelta = 0，Direction 不转
  • velocity.Linear = Direction × 0 = 0，光环仍完全不动
  • 单插 = 废符文；配加速器才活（Lv1加+Lv3导 ≈ 114 °/s）
  • 坠落态例外：ChaseRotateSpeed × 3f 不乘速度 → 自动追踪下一跳

5.7 散射类：不是「算不出锥角」，是「方向没有消费方」

开火锥角走 CalculateRandomAngle（ShootSpellUtils L631–636）： cone = (主动法术.angle + extraScatter) × mul 齐射 Lv1、N=3 时落雷阵确实拿到了 20° 锥角并随机出了偏角——免疫不是发生在这里。 精准施法的 −30/−60/−100 加进去为负，才被钳成 0（L282 快照 + L632–635 锥角各钳一次）。 真正的原因在下游： 偏角 → shootDirection → MovementComponentData.Direction 而落雷阵 Direction × Speed = 0，光环结算只读 Position 和 Radius（系统 L167–168） ⇒ 方向这个量在光环形态下没有任何消费方 （常见误解：SipToSSP 写的 Config.Scatter 快照是另一码事，只有激光 1004 / 分解射线 1011 / 破法者 1021 / 龙息 1025 / 彼岸刃 4019 / 鱼叉 4024 等自己的 Job 读它，1018 不读。）

精准施法 · 只剩一半功能

  • angle 部分纯空转
  • 只剩暴击率 +10/20/40%（1018 基础值为 0）
  • 但预处理对 buffer 每条 TakeDamageInfo 独立掷骰，落雷阵每 tick 每目标各写一条
  • Lv3 满命中 5 s = 140 次掷骰，方差极小 → 期望值利用率全表最高
  • ×2 乘在已 ×0.25 的单 tick 上，总量 ≡ 整段乘 (1+暴击率)

齐射 · 纯正收益

  • int1 加组容量 ✔
  • Pow(float1/100, N−1) 蓝耗折扣 ✔
  • 唯一副作用 int2 散射恶化落空（方向无人消费）
  • 与它在蝴蝶（angle=90）身上的两面性形成直接对照
  • 仅光环态成立：坠落态 Direction 变成第一跳方向，且 ApplyScatterAngleToSpellSIP（L708–714）改抖瞄准点 Target += 随机单位向量 × 锥角×0.06 —— 齐射 20° 锥 ≈ 最多 1.2 单位落点抖动

6.1 闪电链 3007 —— 静止锚点不增伤，但让预算不浪费

TrySpawnLightningChain（SpellShootSystem L606–656）把链建在 相邻两次生成的法术实体之间（SourceEntity=本次, TargetEntity=_lastSpellEntity） 两端存的是实体引用不是坐标，Spell3007Job 每帧重取 LocalTransform（L179–189） → 链的形状完全由两端法术自己的运动决定 落雷阵 shootCount=1 → 需要多重施法 / 齐射同帧另一法术 / 法杖里下一发 提供另一端 一旦成立，就得到全表最干净的「两端都不动」的链。 但它不是一堵能一直打的墙：Spell3007Job L233–262 每完成一次伤害结算就 PenetrateCount--， 归零立刻 DestroyEntity，而 PenetrateCount = 1 + BonusPenetrate ⇒ 没插穿透时基础只有 1，线段第一次打到人就消失，整条链一共只结算一次（Lv3 = 48 点） 所以静止锚点真正改变的不是伤害量，而是这份预算不会被浪费： 飞弹的链要靠「此刻正好扫过敌人」才兑现；落雷阵的链守在原地等人走进来，5 秒内必然兑现。 想当墙用 必须叠穿透去抬 PenetrateCount。

8. 构筑摘要

正收益

  • 悬停（白送满速输出，落雷阵独有）
  • 时长强化（严格线性，蓝耗不涨）
  • 分裂（最强面积扩张，子体满额时长）
  • 毒液晶石（全表最强叠层载体）
  • 齐射（散射恶化被 angle=0 免疫）
  • 伤害强化（每 tick 线性，双形态通吃）
  • 粘液晶石（0.25 s 刷新，debuff 恒定）
  • 公转 / 寻踪 / 多重施法未逆向

要权衡

  • 坠落（换成瞬发爆发，放弃全部区域控制）
  • 节能模式（Lv1 负收益 / Lv2 打平 / Lv3 才划算）
  • 范围增强（面积平方涨，但 int1 截断收益）
  • 精准施法（只剩暴击率，但利用率全表最高）
  • 雷霆晶石（只落 1 次 + 30% 染色骰，期望仅 +12%）
  • 闪电链（需第二个实体；预算必然兑现，但打中一次就断，想当墙要叠穿透）

负收益 / 无效

  • 折射：光环态纯亏（次数白扔 + 全局减伤）
  • 加速器：把区域封锁变成飘走的雷云
  • 反弹：光环态完全无效（无新碰撞事件）
  • 自动导航：Speed=0 → maxDelta=0，纯空转
  • 穿透：costPenetrate:false，零效果
  • 寒霜晶石（20 次尝试只生效 1~2 次）

阵营与目标特例

敌方蝴蝶 / 敌方滚球会被打（RemoveCannotAttackSpell 白名单只有这两个）
可破坏物（木桶/罐子）打不到（Brittleness 被过滤两次）
己方单位 / 己方蝴蝶 / 己方滚球无事发生（两道 IsSameCamp 守卫）
落雷阵本体被攻击不可能——不在白名单里，无生命值，5 秒内不可摧毁
Boss6 二阶段对 1018 有专属免伤冷却（normalSpellClearTime），N² 多段与 4 次/秒都会被节流
