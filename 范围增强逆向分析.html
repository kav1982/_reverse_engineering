范围增强 · Spell3107

Enhance 符文 · ID 31071–31073 · 法术影响半径加算 · 无独立 ECS 行为，只改 extraSizeRatio

1. 是什么

插在主动 / 召唤法术左侧的纯数值符文。把 float1% 写进半径的加算池（AddRatio → extraSizeRatio）。

文案：法术影响半径+float1%。三级同名，只有百分比不同。

  • 没有 Spell3107*System / Authoring
  • 配置标了 haveEffecforSummonSpell=false，运行时不读；手动插在召唤左侧仍生效

3. 叠加：加算，不是连乘

实际 · 加算

  • 2×Lv1 → ×1.60
  • addRatio += 0.30 两次
  • 奥爆术 3 → 4.8

误解 · 连乘

  • 2×Lv1 ≠ 1.3×1.3 = 1.69
  • 不是 3 → 5.07
  • 高级也不会覆盖低级
最终半径 ≈ R × (1 + Σ范围增强float1/100 + 遗物/诅咒半径% + 法杖半径%) × 聚爆乘算 无衰减 · 无上限 · 不取最高级 · 出现几次加几次
SpellShootData.GetSpellEffectRadius谁进加算池 / 谁进乘算池
case EnhanceRadiusRatio:   // 范围增强
    ratioValue.AddRatio(finalConfig.float1 / 100f); break;

case RadiuRatioDown:       // 聚爆
    ratioValue.MulRatio(finalConfig.float1 / 100f); break;

之后拆进 extraSizeRatio（加算）和 finalSizeRatio（乘算）。Mono：spellCfg.radius *= radiusRatio * finalRadiusRatio。ECS：Radius.AddRatio = extraSizeRatio。这一层两边一致。

槽位解析、RatioValue 与伤害强化同一套，见那份文档。这里没有 stopTarget 截断。

4. 两层对照

加算池 AddRatio

  • 范围增强 30 / 60 / 120
  • 遗物 / 诅咒 ExtraRadiusOfInfluence(isSpell: true)
  • 法杖「全杖影响半径%」

乘算层 MulRatio

  • 聚爆 ×50%
  • 个别法术自己再乘 finalSizeRatio
  • 多张聚爆是连乘

遗物自己的圈（圣剑、戒指等）走 isSpell: false，不吃这张卡。

范围增强把半径做大后，聚爆「少掉的米」也变多，转伤更高。这是聚爆吃加算层，不是范围增强自己转伤。

5. 摆放：左侧累积，不清空

只强化自己右边、同一段里的主动 / 召唤。主槽加不到后槽。

范奥爆弹 → 两张都吃
奥爆范弹 → 只有弹吃
奥爆弹范 → 都吃不到（强化在右侧）

自动填槽只配给表里 radius > 0 的主法术；流星、火球、死亡蝰蛇会被避开。手动摆不受影响。

6. 实际放大什么

不自己画圈，只提高 radiusRatio。谁乘这个倍率，谁就变大。

  • 表半径（奥爆术 R=3）
  • 爆炸 / 坠落炸 / 虚空炸
  • 公转半径、部分弹体缩放
  • 召唤物拾取、自爆、探测
  • 闪电链牵引（从宿主抄倍率，自己不单独结算）

不是射程。 不改速度、持续时间、蓝耗。

魔法弹等 radius=0：配置半径仍是 0，硬编码圈照样 +30%。自动填槽不会给它们配这张卡，手动摆仍然生效。
