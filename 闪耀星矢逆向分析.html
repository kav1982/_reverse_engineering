闪耀星矢 · Spell1026

主动蓄力飞弹 · ID 10261–10263 · 蓄力加暴击，达阈值最终伤害乘算 · ECS 主轨 / Mono 旧轨

1. 是什么

按住蓄力的法术飞弹。蓄力期间暴击率随时间上涨；松手时若暴击率 ≥ float3%，最终伤害 × float2%。视觉按暴击率分 4 档，紫光为满档。

文案：蓄力施法，每秒暴击 +float1%；暴击超过 float3% 时最终伤害 ×float2%。

3. 主流程（ECS）

生成 Entity（ChargeData + ChargingTag） → DisableCollider：记 baseCritical、关碰撞、估初档 → ChargeSystem：ChargeTimer+=dt；松手关 ChargingTag → ChargingSystem：crit 上涨、升档 Shine/Flash、体积 → 松手：Trail/Shoot/后坐力 → EndCharging 恢复碰撞 + 倍率 → 命中 Hit_1..n；坠落 Fall 粒子
  • 蓄力期碰撞 None，避免贴身误伤
  • Stage 4 关 Charge_Charge 环 → 对应「紫光满蓄」
  • ReadyToShoot 只写不读，疑似死字段
Spell1026ShiningStarChargingSystem.cs蓄力刷新
CriticalChance = baseCritical + chargeTimer * 0.25f;
CurStage = clamp(Ceil(CriticalChance / 0.33f), 1, 4);
// 升档：Charge_Shine_{stage} + Flash_{stage}
// Scale = Pow(1.1f, CurStage)
if (CurStage == 4) ChargePrefab.SetActive(false);

4. 双轨对比

ECS 主轨（复刻以此为准）

  • 暴击增速硬编码 0.25/s
  • Damage.MulRatio *= Float2/100
  • 无阵营限制
  • 可叠加溢出暴击转伤

Mono 旧轨

  • 读配置 float1
  • 直接改 spellCfg.damage
  • 仅玩家吃 float2
  • SpellChargeStageCalculator 定档
