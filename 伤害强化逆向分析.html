3. 叠加：加算，不是连乘

实际 · 加算

  • 2×Lv1 → ×1.50
  • addRatio += 0.25 两次
  • 魔法弹 10 → 15

误解 · 连乘

  • 2×Lv1 ≠ 1.25×1.25 = 1.5625
  • 不是 10 → 15.625
  • 高级也不会覆盖低级
加算倍率 = 1 + Σ(float1 / 100) 仅伤害强化时：伤害 = B × 加算倍率 无衰减 · 无上限 · 不取最高级 · 出现几次加几次
RatioValue.cs加是 += ，乘是 *=
public double ResultDouble =>
    (BaseValue + addBase) * baseAddRatio * addRatio * mulRatio + addExtra;

public RatioValue AddRatio(double val) { addRatio += val; return this; }
public RatioValue MulRatio(double val) { mulRatio *= val; return this; }
CanShootSpellUtils.GetDamage谁进加算池 / 谁进乘算池
case EnhanceAttackRatio:   // 伤害强化
case FireCrystal:          // 炽焰晶石
case OverDrive:            // 过载
    ratioValue.AddRatio(enhance.float1 / 100f); break;

case Refraction:           // 折射
    ratioValue.MulRatio(enhance.float2 / 100f); break;
case PowerSavingMode:      // 节能
    ratioValue.MulRatio(enhance.float3 / 100f); break;

主动法术的 stopTarget 是自己，不在 EnhanceList 里，所以列表里每张伤害强化都会加上。截断只发生在闪电链 / 生命线以「强化自己」为基数时。

4. 两层对照

加算池 AddRatio

  • 伤害强化 25 / 50 / 100
  • 炽焰晶石 +100
  • 过载 +50 / +100 / +200
  • 玩家 ExtraDamageRatio
  • 低耗高伤法杖 float1

乘算层 MulRatio

  • 折射 ×80 / 85 / 90%
  • 节能 ×75 / 75 / 80%
  • 法杖 passiveDamageRatio
  • 法杖 damageCorrection/100
  • 多张折射 / 节能是连乘
最终伤害 ≈ Ceil( B × (1 + Σ加算% + ExtraDamageRatio + …) × Π 折射(float2/100) × Π 节能(float3/100) × wand.passiveDamageRatio × damageCorrection/100 ) + extra
SpellInitialParameter / SpellBase实伤拆层
extraDamageRatio += ExtraDamageRatio;
extraDamageRatio += GetSpellDamage().CurrentAddRatioStartZero; // 从 0 起算
finalDamageRatio *= GetSpellDamage().CurrentMulRatio;
finalDamageRatio *= wand.passiveDamageRatio * (damageCorrection/100);

damageRatio += extraDamageRatio;          // 初值 1
spellCfg.damage = Ceil(B * damageRatio * finalDamageRatio) + extra;
AttributeValue.CalculateECS 同一层，AddRatio 存增量
(Base + AddBase) * (1 + AddRatio) * MulRatio + Extra
// AddRatio = sip.extraDamageRatio（0.25 而不是 1.25）

5. 摆放：左侧累积，不清空

SpellGroupParser 从左到右把 Enhance 推进 list2，遇到主动法术后也不清空。主槽 / 后槽分段 Parse，互不加。

强弹球 → 弹 ×1.25 · 球 ×1.25（同一张往后传）
弹强球 → 弹 ×1.00 · 球 ×1.25
强A弹强B球 → 弹只吃 A · 球吃 A+B
弹球强 → 两边都不吃（强化在右侧）
SpellGroupParser.cslist2 只加不减
if (useType == SpellType.Enhance) { list2.Add(item); continue; }
list.Add((item, list2.ToArray()));   // Missile / Summon 拿走快照

7. 闪电链 / 生命线

不走主动法术的 B，用强化自己的基数 + GetDamage_FinalPlayerValue，stopTarget = 该张强化。

强链弹 → 链基数 12 吃 +25% · 弹也吃
链强弹 → 链不吃（强化在右侧）· 弹吃 +25%

伤害强化自己不产链 / DoT，只改别人的 AddRatio。细节见闪电链文档。
