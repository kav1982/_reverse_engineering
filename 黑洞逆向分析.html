黑洞 · Spell1007

Missile 主动法术 · ID 10071–10073 · isDPS 驻场圈 · 每 0.25s 圈伤 + 向圆心拉人 · Lv2/3 胀圈

1. 是什么

一颗 1.2 m/s 的慢速圈。每 0.25 秒对 Radius.Calculate() 内全部可攻击目标打一刀（单次 = 表伤 × 0.25），并按 float2 × 0.25 把玩家阵营打中的单位拉向圆心。Lv1 不胀圈；Lv2/3 按 float1/2 m/s 胀大底数。

文案：机制栏 Lv1 为空，Lv2「缓慢增长」、Lv3「增长」。风味「吸引 + 伤害 + 升级提升体积」三句都能在代码里落地。

  • ECS 主路径：Spell1007Job（胀圈 / DPS）+ SpellTakeDamageResultSystem（牵引）+ 通用 Normal_Common（位移）
  • Mono Spell1007BlackHole 为残留轨。它的拉力抄的是 knockback=0，整段是死的
  • float3=25 是死字段；旧工具把 float2 也标成未读，过期
  • CalculateSpellComplexity 记 4 分；自动填槽推荐当后槽触发器扔

3. 核心机制：胀圈 → 圈伤 → 牵引

config.DamageTimer += DeltaTime;
float num = config.Float1 * DeltaTime / 2f * TimeScale;
config.Radius.Base += num;                    // 坠落也胀
if (movement.IsFallSpell) return;             // ← 关掉 DPS / 拖尾

if (config.DamageTimer < config.DamageInterval) return;
GetAttackableEntitiesInRange(..., Radius.Calculate(), containsBrittleness: true);
NewInfo(..., CostPenetrate: false);           // 伤 = damage × 0.25
// 每个目标 TryAttackEntity
config.DamageTimer -= config.DamageInterval;

    {
        float3 dir = DTool.IgnoreZDir(spell.Position, hitPosition);  // 指向圆心

Job 不设生命周期门

  • 不读 DurationTimer / HoverTimer
  • 实体还在，DPS / 拉 / 胀就转
  • 悬停期继续满速输出（已核验）
  • CostPenetrate=false，打不完自己

不是这样

  • 不是每帧连续引力场
  • 不是配置 knockback（那条是 0）
  • 不是落地变成地面光环
  • 己方蝴蝶不会被自己的圈打碎

5. 坠落：×6 不是主要影响

  • 水平 1.2 × 6 = 7.2，几乎是砸下去
  • Spell1007Job 遇 IsFallSpell 提前 return → 途中不 DPS、不牵引，圈还在胀
  • 落地走同一个 NewInfo，仍 ×0.25，不是满额（Mono 才是满额）

8. 构筑速查

正收益

  • 悬停（第二段满速）
  • 时长强化（+tick，Lv2/3 还多胀）
  • 伤害强化 / 精准暴击
  • 毒液晶石（20×int2，还拉人）
  • 范围增强（出生圈 + 膨胀段）
  • 分裂（结束再铺一圈小黑洞）

要权衡

  • 齐射（多圈，但 int2 打散）
  • 自动导航（有追踪，但转不动）
  • 聚爆（Lv1 只缩不转伤）
  • 寒霜（只有第一 tick 过门）

负收益

  • 坠落：关掉 DPS + 牵引
  • 加速器：驻场圈飞走
