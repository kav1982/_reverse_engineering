自动导航 · Spell3011

Enhance 符文 · ID 30111–30113 · 以 float1°/米跟踪目标 · 轨道类右优先，卡面「随机」与代码不符 · 回旋镖 33% 只覆盖 ChaseEnemy，见《回旋之刃逆向分析.md》

1. 是什么

插在主动 / 召唤左侧的轨道符文。运动类型改成 ChaseEnemy，按 float1 °/米转朝向。不改伤害、半径、速度、蓝耗、飞行寿命。

文案：法术以 float1° 每米的角速度跟踪目标。底部写「不同轨道类强化同时存在时会随机选取」——代码不是随机。

  • 没有 Spell3011*System / Authoring
  • 配置标了 haveEffecforSummonSpell=false，运行时不读
  • 每飞 1 米最多转 float1 度；和速度解耦，跟路程走

3. 叠加

同卡：加算 °/米

实际 · Σfloat1

  • 2×Lv1 → 24°/m
  • 底数从 0 加
  • 手摆可叠；自动填槽组互斥

误解

  • 不是 max(12, 12) = 12
  • 不是 °/秒
  • 不是一张高级 = 两张低级
SpellShootData.GetChaseEnemyRotateSpeed同卡相加
return EnhanceList
    .Select(e => e.GetFinalConfig())
    .Where(e => e.abilityType == FollowTarget)
    .Sum(e => e.float1);

Mono 同样是 spellFollowTargetRotateSpeed += float1。魔能升阶走 GetFinalConfig()。

4. 转向：°/米，不是 °/秒

maxDelta = Speed × float1 × dt Direction = DirMoveTowards(当前朝向, 指向目标, maxDelta) R ≈ 180 / (π × float1) 米 Lv1 ≈ 4.77 m，Lv2 ≈ 2.60 m，Lv3 ≈ 1.51 m 总转角 ≈ float1 × 速度 × Duration
SpellBase.SpellFollowTargetMono · 有目标才转
if (SpellFollowHaveTarget)
{
    Direction = DirMoveTowards(Direction, ToPointDir(target),
        CurrentSpeed * rotateSpeed * dt);
    velocity = Direction * CurrentSpeed;
}
else
    target = GetMiniMalAngleTargetablePpt();

ECS SpellMoveJob.Normal_ChaseTarget 同一套。两边都把 float1 当度（MoveTowardsAngle / math.radians）。

自动导航不加 Duration。短寿命弹要转够，得叠角速度、加时长或加速度把路程拉长。悬停后速度为 0，不再转。

锁敌：最小夹角，粘住

  • 不是最近距离。取与当前朝向夹角最小的可锁定单位
  • 目标还活着且 CanBeTarget：粘住，不因旁边夹角更小而换
  • 目标没了：当帧直线飞，再重新取最小夹角；没有目标就直线
  • 默认不穿墙检测。墙后的怪也能锁
  • 玩家弹锁敌对；ECS 额外排除 NotAttack、Brittleness

5. 摆放：左侧累积

只强化自己右边、同一段里的主动 / 召唤。主槽加不到后槽。

导弹 → 弹跟踪
弹导 → 吃不到
导奥爆弹 → 两张都吃（奥爆常关掉通用跟踪）
导召唤 → 运行时仍写入（表标无效，但不读）

自动填槽不在 IgnoreSpells。流星 / 火球 / 死亡蝰蛇只避开自我追踪和范围增强，不避开自动导航。

第四类：Speed = 0，通用公式整体空转

法术插上导航之后
落雷阵 1018 光环态（speed = 0）Type 确实写成 ChaseEnemy，但 switch 里没有 ThunderAura case → Normal_ChaseTarget。maxDelta = 0、velocity.Linear = 0，一度不转、一米不动。单插是废符文
落雷阵 1018 坠落态例外，有效：Spell1018FallJob.CalcFallTargetPosition（Spell1018ThunderAuraSystem.cs L849–864）自己实现一套 ChaseEnemy，DirMoveTowardsIgnoreZ(..., ChaseRotateSpeed × 3f) 不乘 Speed
// SpellMoveJob.Normal_ChaseTarget L541–545 num = IsFallSpell ? OriginalSpellHorizontalSpeed : Speed; Direction = DirMoveTowardsIgnoreZ(Direction, 敌向, num * ChaseRotateSpeed * dt); velocity.Linear = Direction * Speed; Speed = 0 → maxDelta = 0（不转） 且 velocity = 0（不动） ← 两处都被归零 配加速器才活：[加Lv1(+3)] [导Lv3(38)] [落雷阵] → 3 × 38 = 114 °/s

这张卡的效果挂在路程上（路程 = Speed × 时间），而它自己既不加速度也不加时长 → 强度和载体速度是乘性的：Speed=0 必然空转、速度极低要么是降级（蝴蝶：顶替了更好的原生转向）要么弱到可以忽略（黑洞：补上了追踪但 14 °/s 转不动）、速度高才划算。[加Lv1] [导Lv3] [落雷阵] 能救回来，但占两槽，且加速器单插对落雷阵 / 黑洞本身是负收益（见 加速器逆向分析.md 3.4）。[坠落] [反弹] [导航] [落雷阵] = 会自动追着敌人跳的连锁落雷。详见 落雷阵逆向分析.md 7.10、黑洞逆向分析.md 7.1。

持续施法距离：自动导航不加额外秒数；只有公转会折进部分持续法术。蝴蝶是全表唯一把 float2 乘进距离估算的法术（速度 × 时长 × 0.15），与导航无关。详见 蝴蝶逆向分析.md 7.1。

7. 开发注意事项

运动

  • 按路程转，不要做成 °/秒
  • 速度为 0 就不再转
  • 锁最小夹角，粘住

叠加

  • 同卡加算，跨轨道右优先
  • 卡面「随机」不要做成洗牌
  • ECS 只加赢了的那种角速度

例外

  • 激光族 / 喷流不走通用路径
  • 流星会把角速度放大
  • 蝴蝶：导航是覆盖，结果变钝
  • 落雷阵：Speed=0，纯空转
  • 「对召唤无效」运行时不读
