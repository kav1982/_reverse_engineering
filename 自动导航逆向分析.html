自动导航 · Spell3011

Enhance 符文 · ID 30111–30113 · 以 float1°/米跟踪目标 · 轨道类右优先，卡面「随机」与代码不符

1. 是什么

插在主动 / 召唤左侧的轨道符文。运动类型改成 ChaseEnemy，按 float1 °/米转朝向。不改伤害、半径、速度、蓝耗、飞行寿命。

文案：法术以 float1° 每米的角速度跟踪目标。底部写「不同轨道类强化同时存在时会随机选取」——代码不是随机。

  • 没有 Spell3011*System / Authoring
  • 配置标了 haveEffecforSummonSpell=false，运行时不读
  • 每飞 1 米最多转 float1 度；和速度解耦，跟路程走

3. 叠加

同卡：加算 °/米

实际 · Σfloat1

  • 2×Lv1 → 24°/m
  • 底数从 0 加
  • 手摆可叠；自动填槽组互斥

误解

  • 不是 max(12, 12) = 12
  • 不是 °/秒
  • 不是一张高级 = 两张低级
SpellShootData.GetChaseEnemyRotateSpeed同卡相加
return EnhanceList
    .Select(e => e.GetFinalConfig())
    .Where(e => e.abilityType == FollowTarget)
    .Sum(e => e.float1);

Mono 同样是 spellFollowTargetRotateSpeed += float1。魔能升阶走 GetFinalConfig()。

SpellShootDataExtend.GetSpellMovementType从右往左取第一种
for (int i = EnhanceList.Length - 1; i >= 0; i--)
{
    switch (EnhanceList[i].GetFinalConfig().abilityType)
    {
        case AroundOwner:
        case RandomRotationRadiu: return Rotation;
        case AroundMouse:         return ChaseMouse;
        case FollowTarget:        return ChaseEnemy;
        case FollowOwner:         return ChaseOwner;
    }

ListShuffle 的 list 从未 Add，是死代码。繁中「覆蓋之前的彈道」才对。ECS 只加赢了的那种角速度。

自动填槽 RepelSpellGroup：公转 / 寻踪 / 导航 / 自我追踪四张一组，同一段最多一张。自由公转不在这组。手摆不受限。

4. 转向：°/米，不是 °/秒

maxDelta = Speed × float1 × dt Direction = DirMoveTowards(当前朝向, 指向目标, maxDelta) R ≈ 180 / (π × float1) 米 Lv1 ≈ 4.77 m，Lv2 ≈ 2.60 m，Lv3 ≈ 1.51 m 总转角 ≈ float1 × 速度 × Duration
SpellBase.SpellFollowTargetMono · 有目标才转
if (SpellFollowHaveTarget)
{
    Direction = DirMoveTowards(Direction, ToPointDir(target),
        CurrentSpeed * rotateSpeed * dt);
    velocity = Direction * CurrentSpeed;
}
else
    target = GetMiniMalAngleTargetablePpt();

ECS SpellMoveJob.Normal_ChaseTarget 同一套。两边都把 float1 当度（MoveTowardsAngle / math.radians）。

自动导航不加 Duration。短寿命弹要转够，得叠角速度、加时长或加速度把路程拉长。悬停后速度为 0，不再转。

锁敌：最小夹角，粘住

  • 不是最近距离。取与当前朝向夹角最小的可锁定单位
  • 目标还活着且 CanBeTarget：粘住，不因旁边夹角更小而换
  • 目标没了：当帧直线飞，再重新取最小夹角；没有目标就直线
  • 默认不穿墙检测。墙后的怪也能锁
  • 玩家弹锁敌对；ECS 额外排除 NotAttack、Brittleness

5. 摆放：左侧累积

只强化自己右边、同一段里的主动 / 召唤。主槽加不到后槽。

导弹 → 弹跟踪
弹导 → 吃不到
导奥爆弹 → 两张都吃（奥爆常关掉通用跟踪）
导召唤 → 运行时仍写入（表标无效，但不读）

自动填槽不在 IgnoreSpells。流星 / 火球 / 死亡蝰蛇只避开自我追踪和范围增强，不避开自动导航。

7. 开发注意事项

运动

  • 按路程转，不要做成 °/秒
  • 速度为 0 就不再转
  • 锁最小夹角，粘住

叠加

  • 同卡加算，跨轨道右优先
  • 卡面「随机」不要做成洗牌
  • ECS 只加赢了的那种角速度

例外

  • 激光族 / 喷流不走通用路径
  • 流星会把角速度放大
  • 「对召唤无效」运行时不读
