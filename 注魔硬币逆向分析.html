注魔硬币 · Spell1020

Missile 主动法术 · 仅 ID 10201 · 特殊掉落 · 首帧扣当前金币 20% 换基础伤害 · 销毁后原地吐回

1. 是什么

射出一枚实体飞弹。首帧按当前金币的 20%（向上取整）扣钱，每扣 1 枚给这发弹 Damage.AddBase += 6。飞 2 秒，直线，默认打一个目标就销毁。销毁当帧在落点吐出刚才扣掉的金币，走近捡回来就回本。

文案：7110201「消耗并射出 float1% 的金币，每消耗 1 枚基础伤害 +float2。结束时金币重新掉落」。三条都是真机制。ECS 把第一句的 float1 写成了字面量 0.2f，和表值 20 碰巧相等。

  • ECS：Spell1020ManaCoinSystem（扣金加伤）+ 通用 SpellMoveJob.Normal_* + Spell1020GroundCoinSpawnerSystem（吐钱）
  • 落地堆是 Spell10201Coin，不是法术实体；拾取在 PlayerControllerSystem
  • Mono Spell1020ManaCoin 为残留轨，100 金时打 132，ECS / UI 打 180
  • 只有 Lv1，不可合成；CalculateSpellComplexity 记 2 分

3. 核心机制：扣金 → 加伤 → 吐回

Spell1020ManaCoinSystem.OnUpdateL220–261 · 每实体只进一次
int num = Mathf.CeilToInt(PlayerMgr.Inst.CoinCount * 0.2f);
if (!同阵营玩家) num = 0;
if (IsSplitSpell) {
    num = 0;
    Damage.AddRatio += Int3 * Float2 / 100f;   // 子弹：再叠一层比率
}
PlayerMgr.Inst.ChangeCoin(-num);
Damage.AddBase += num * Float2;
CoinUseCount = num;
  • 同一帧多枚未初始化的硬币顺序扣：后一发看见的是已经被扣过的余额
  • 没钱 / 非玩家：num=0，银色空壳，落地不掉钱
  • 虚空染色优先于金银
  • BuffRatio 烘焙后从未再写；GroundCoinsBuffer 只挂不读——两个死件

伤害强化 / 节能的比率会乘到 used × 6 上。100 金时 +120 这笔加算，插伤强 Lv3 变成 +240。

4. 弹道：没有专属位移

没有 SpellMoveJob 的 ManaCoin case，也没有发射烘焙。默认 Normal_Common 直线。自动导航 / 寻踪 / 公转 / 坠落全部落到对应的 Normal_*。寿命走通用 4.1（2 秒 → 停 → 悬停 → 销毁）。自带穿透 = 0。

5. 落地金币

Spell1020GroundCoinSpawnerSystem 在 SpellEndSystemGroup，先于 SpellDestroySystem（OrderLast）。销毁当帧：先吐钱，再分裂，再删母弹。

  • CoinUseCount > 0 才生成 Spell10201Coin
  • Theme6 / 第三章捷径会把落点夹进房间矩形
  • 堆外观：>50 / >20 / >10 四档模型；落地动画结束后才开 Layer_InteractiveObj
  • 走近：ChangeCoin(+used)。不走普通金币拾取，不滚捡钱掉血诅咒
  • belongRoomMapPos：切房再回来会按金额重建，不会蒸发
分裂子弹（100 金、used=20） 母弹伤害 180 → ToSplit ×0.33 → 快照 59.4 子弹再 AddRatio += 20×6/100 = 1.2 单发子弹 = 59.4 × 2.2 = 130.68 母弹的金币加算已经在被复印的 Damage 里 子弹又按同一笔 used 加了一层 120% —— 双重计算 BuffRatio / Float3 全程空转

9. 构筑摘要

正收益

  • 身上有钱（线性换伤，打完能捡回）
  • 伤害强化（连金币加算一起乘）
  • 分裂（一笔钱打母弹 + 打裂片）
  • 穿透（才能在吐钱前打多个）

中性 / 看情况

  • 时长 / 悬停：只推迟吐钱
  • 加速器 / 导航：只改弹道
  • 齐射：不复制这张卡
  • 节能：效率比 1.25，但加算也被砍

注意

  • 没钱 = 银色 60 伤空壳
  • 默认无穿透，打一下就吐钱
  • 组里多张硬币顺序扣，后发更瘦
  • 记得捡；切房不会丢
