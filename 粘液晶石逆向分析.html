粘液晶石（Spell3004 / MucusCrystal）逆向分析

范围：仅玩家强化符文「粘液晶石」（abilityType = 3004，配置 ID 30041–30043）。重点是法术侧怎么合成一包粘液数据，以及命中后 SetMucus 怎么覆盖。

不展开敌人史莱姆弹、药水免疫、地上粘液怪。共享「元素附着」管线写在第 5 节，不逐条展开冰冻 / 毒 / 燃烧。

方法：SpellConfig.json + 反编译 Assembly-CSharp 交叉验证。未标注「推测」的结论均有代码/数据直接证据。

玩家施法主路径是 ECS。Mono SpellBase 叠加上限与 ECS 基本一致，时长取法不同，文末单独对照。

配套：总览见《魔法工艺法术系统逆向报告.md》，原始数值见《法术数值总表.md》，槽位解析骨架见《伤害强化逆向分析.md》，子弹整包继承元素见《分裂逆向分析.md》。

文案（TextConfig_Spell id 7130041–7130043）：

法术命中单位后使其在 float1 秒内移动速度×float2% 且施放的法术飞行速度×float3%

名称（7030041–7030043）：粘液晶石 / Slime Crystal。三级名称相同，只有三个 float 不同。底部补充（7230041）见第 5 节。

2. 数值与叠加

2.1 配置表

IDLevelfloat1 持续秒float2 移速×%float3 飞行速度×%售价可合成
300411360706true
3004224455018true
3004335303054false

售价每级 ×3。等级不是「每级 ×2」：时长微增，两个减速系数各自变狠。比伤害强化（9/27/81）便宜一档。

2.2 字段语义

字段语义运行时是否被读置信度
float1附着时长（秒）；多张取 Max是高
float2目标移速系数（「×float2%」）；多张 连乘 float2/100是高
float3目标自己施放的法术飞行速度系数；多张连乘是高
int1 / int2 / int3配置为 0ECS 未读高
haveEffecforMissile/Summon对弹幕与召唤都标为生效GetMucusElementData 不读高

float2=60 就是 ×0.6（慢 40%），不是再乘一次 60%。

2.3 法术侧：组卡时合成一包（Max + 连乘）

GetMucusElementData():
  duration = Max(各张 float1)          // 初值 0
  moveSpeedRatio *= float2 / 100      // 初值 1
  spellSpeedRatio *= float3 / 100     // 初值 1

同类型出现几次乘几次。无上限、不「只取最高级」。初始必须是 (1, 1, 0)，从 0 连乘会锁死。

等级不能按「2×Lv1 = 1×Lv2」换算：

2×Lv1：时长 3，移速 ×0.36，飞行 ×0.49   （更慢，更短）
1×Lv2：时长 4，移速 ×0.45，飞行 ×0.50
1×Lv3：时长 5，移速 ×0.30，飞行 ×0.30

合成省槽，也换「更长、单卡更狠」；多张低级在减速上往往更狠。

2.4 目标侧：命中时覆盖，不是再乘

法术侧（组卡）目标侧（命中）
时长多张取 Max新时长 > 剩余才刷新，短的砍不短
移速 / 飞行系数多张连乘直接覆盖，再钳到 [0, 1]
后一发较弱的粘液会把已经更慢的系数盖回去。精英 / Boss 时长再乘 frozenTimeRatio（常见 Boss 0.1，玩家 0.5，小怪 1），和冰冻共用这个字段。系数不乘。免疫或无敌直接 return。

3. 谁吃得到这张卡

3.1 只强化自己右边、同一段

粘弹→ 弹带粘液
弹粘→ 弹带不到
粘弹弹→ 两发都带
粘A弹粘B滚球→ 弹吃 A；滚球吃 A+B

主槽加不到后槽。自动填槽 SelfRepelSpells 含粘液晶石，同一根杖不会自动再塞第二张；手摆可以叠。

3.2 命中还有一道门

immuneDamage 或 damage <= 0：只结算击退，整包元素都不挂。条件是 MucusDuration > 0，不是看外观颜色。

3.3 玩家也能被挂

玩家 800001：immuneMucus=false，frozenTimeRatio=0.5。「飞行速度×70%」减的是被命中单位往外射的法术，不是你这发弹自己的速度。

4. 主路径与边界

4.1 命中后

affect_IsMucusHit = true，身体染 color_BodyMucus（黄 1,1,0），脚底特效 3004_Decelerate。倒计时到点 ClearMucusState。affect_IsMucusDecelerate 只驱动特效，不是第二套数值。

4.2 分裂

ToSplit 整包复制 ElementComponentData。子弹拿到发射时的满额时长和连乘系数，命中仍走 SetMucus。

4.3 悬停 / 坠落 / 爆炸圈

只要打出 damage > 0 的伤害信息，就走同一条元素门。圈的大小是范围增强的事；粘液只问这发实体上的 MucusDuration 是否 > 0。

4.4 闪电链 / 生命线 / 召唤

对象怎么带粘液
闪电链 ECS从宿主抄整份 SpellElementEffectComponentData
闪电链 / 鱼叉链 / 生命线 Mono抄 spellMucusTime 和两个 ratio
召唤物攻击 / 撞击生成时带上召唤法术的 Element，或从召唤者再 SetMucus
只拷 ColorType会丢减速

4.5 彩虹丝带 / 随机色杖

先定 ColorType，再 ApplyElementSpell(ToSpellId)。抽到粘液时再灌一张对应等级晶石：时长取 Max，两系数再乘一次。已经插了粘液晶石、彩虹又抽到黄色：系数会再乘一张 Lv1。

4.6 公转 / 寻踪 / 反弹 / 穿透

不改粘液数据包。穿透耗尽会在单位身上销毁，但已经打出的那下若 damage > 0 仍会挂粘液。

5. 共享元素附着管线

当存在多种元素附着强化时，外观上会随机选择一种颜色，但命中目标时仍然产生所有元素附着强化的效果。

5.1 颜色只决定外观（和地面痕迹）

abilityType颜色
粘液 3004Mucus
毒液 3005Venom
寒霜 3014Frozen
炽焰 3111Fire
坍缩 3129Void

雷晶石不在这张映射里；它用 float3 概率先改成 Thunder。没有元素色时回落到 Player。

5.2 效果按数据全上

UnitPropertyJob 对毒 / 冰 / 粘 / 烧 / 虚空是并列 if。弹是火颜色，只要 MucusDuration > 0 仍会减速。

5.3 地面痕迹跟颜色，不跟效果包

ColorType == Mucus 才会 CreateMucusRequest。带了晶石但随机成毒色：命中仍减速，不铺地。

晶石命中踩到地上粘液
条件MucusDuration > 0 且伤害 > 0颜色是黄留下的 MucusTag；非飞行、非免疫地面
移速法术包里的连乘系数固定 Min(0.6, 当前系数)
飞行速度有无
时长float1（精英/Boss 再乘 frozenTimeRatio）站上去才有，离开即无
与晶石共存—已有 affect_IsMucusHit 时不再吃地面层

6. 算例

普通小怪（frozenTimeRatio=1），先不算彩虹丝带。

槽位命中后（移速 ×，飞行 ×，秒）
[弹]无
[粘Lv1] [弹]×0.60 / ×0.70 / 3
[粘Lv2] [弹]×0.45 / ×0.50 / 4
[粘Lv3] [弹]×0.30 / ×0.30 / 5
[粘Lv1]×2 [弹]×0.36 / ×0.49 / 3
[粘Lv1][粘Lv2] [弹]×0.27 / ×0.35 / 4
先 Lv3 再被 Lv1 打中系数变成 ×0.60 / ×0.70，剩余时长仍按较长的那头
打在 frozenTimeRatio=0.1 的 Boss 上时长 0.5 秒，系数仍是法术包里的值
[粘Lv1] [弹] + 彩虹抽到黄×0.36 / ×0.49 / 3（再乘一张 Lv1）

[粘][毒][弹]：外观黄或绿各 50%；命中同时上粘液和毒。

7. Mono 残留轨对照

两系数连乘与 ECS 一致。时长写成 Mathf.Max(spellConfig.float1)（单参数，等于覆盖成最后一张）。ECS 是对已有值取 math.max。玩家主路径以 GetMucusElementData 为准。
