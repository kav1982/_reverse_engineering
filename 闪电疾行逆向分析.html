闪电疾行 · Spell1016

Missile 主动法术 · ID 10161–10163 · 稀有 · 法术反过来驾驶施法者 · 全程无敌 · 结束后按驾驶时长过热 · 击退 20 为全表最高

1. 是什么

这不是一发「打出去的弹」，而是一发反过来把施法者装进去开走的载具。开火当帧法术实体给施法者挂上 FlyRegister() + InvincibleRegister()，此后每帧把施法者的 LocalTransform.Position 强制同步到法术实体身上。玩家在这 1 秒里全程无敌、碰撞体关闭、可用 WASD 瞬时改向、撞墙无限反弹、碾过的敌人吃 damage + 击退 20。结束后按实际驾驶时长换算出一段「过热」——过热期间这根法杖打不出任何含冲刺的法术组。

Lv2/3 在销毁点额外炸一圈 Radius × Float1，并清掉圈内绝大部分敌方飞弹。

  • ECS 主路径：6 个专属系统（DashSystem / HitEffectSystem / EndSystem / OverheatSystem / CleanupSystem / EffectDestroySystem）
  • 照常进 SpellPhysicsSystemGroup —— 它是货真价实的物理弹，和激光的一次性几何完全相反
  • duration = 1.0 真的被读：同时是飞行段长度、无敌窗口、过热输入（一个字段管三件事）
  • Mono Spell1016Dash（约 930 行）为残留轨，ECS 版是它的简化重写，丢了若干特性，见第 8 节
  • CalculateSpellComplexity 记 7 分（与彩虹同档；激光只有 3 分）

不要和精英怪的「闪电急行」混淆：Elite13.cs 里那个 [Header("闪电急行")] 分组是完全独立的怪物状态机（MonsterState.LightningDashAfter 等），不走 SpellAbilityType.Dash、不生成 1016 实体、没有过热与驾驶权单例。「急」vs「疾」一字之差，两者没有任何代码共享。Monster308DashSystem / Boss13DashBullet / Boss13DashLaser 同理。

为什么公转要清空 AroundTarget

Spell1016DashSystem L976–982： movement.AroundTarget = Entity.Null; SpellMovementComponentData L77–90： 有 AroundTarget → 圆心每帧跟着那个实体走 无 AroundTarget → 用 AroundCenter（自由点） 若不断开就会自激：球绕玩家转 → 玩家被球拽着走 → 圆心跟着玩家跑 → … 清空是打断这个循环的必要操作，圆心从此变成一个由 WASD 推的自由点。

驾驶权单例：一人同时只能被一发冲刺开走

4. 过热 · 本文核心结论

Spell1016CleanupSystem.GetOverheatTime · 过热曲线L251–268
if      (duration <= 1f)   overheatTime = duration;
else if (duration <= 8f)   overheatTime = 0.357f * duration + 0.643f;

过热锁「组」不锁「杖」

Wand.CanShoot / Wand.TryShootL1968–1971、L2022–2025
// CanShoot：当前组里只要有一张冲刺，整组不能开火
if (PlayerCtrller.isDashOverHeat && currentShootGroup.HasShootableSpell(SpellAbilityType.Dash, deepSearch: false))
    return false;

// TryShoot：同样条件下直接跳到下一组，并照常吃冷却
if (currentShootGroup != null && PlayerCtrller.isDashOverHeat && currentShootGroup.HasShootableSpell(...))
    EnterNextGroup(setCoolDownOrInterval: true);

这是冲刺构筑最重要的一条排版规则，游戏内没有任何提示：冲刺单独占一组时，过热期间会自动轮空那一组继续打别的组；冲刺和输出法术挤在同一组时，过热就是整组停摆。注意 deepSearch: false——只看当前组的直接槽位，不递归子组。

过热注册是取大值不是累加： if (!(duration <= dashOverHeatTimer)) { dashOverHeatTimer = duration; ... } 倒计时挂在 PlayerController.Shoot() 的第一行（在所有 early-return 之前）： dashOverHeatTimer -= PlayerMgr.Inst.PlayerDeltaTime; ← 用 PlayerDeltaTime，子弹时间可能拉长过热（未验证） UI 一根条复用两个含义（UIPlayerDashProgressBar）： 冲刺中 → DashRemainingTime / TotalDashTime（满→空） 过热中 → 1 - dashOverHeatProgressRatio（空→满） 队友 / 怪物冲刺不会点亮这根条（SetDashTime 只在 unitType == Player 时调）

齐射 / 多重施法：一发载人，其余全是自由炸弹

① 同帧生成 N 发冲刺 → 都跑首帧逻辑 ② 第 1 发 ShooterDrive 成功，载人 ③ 第 2..N 发撞上 IsShooterDriving == true → continue → Dirver = Null ④ 这 N−1 发照常飞、照常碾人（伤害系统不看 Dirver），但不顿帧、不放命中粒子 ⑤ 销毁时每一发都独立跑一次结束爆炸 + 弹幕清除 + 雷霆晶石落雷（EndSystem 不看 Dirver） ⇒ [齐射Lv3][冲刺Lv3][X][Y] 会在同一片区域炸出 N 个半径 3.5 的圈并清 N 次弹幕。 多重施法不被钳制：ShootSpellUtils L756–761 强制 count = 1 的名单是 BiAnLethalBlade / LaserBeam / BlueRune / RedRune / GreenRune —— 不含 Dash 现实约束：Lv3 蓝耗 56 会按份数乘；复杂度 7 分会让低帧优化更早砍数量。

[寻踪][冲刺] = 「用鼠标画路线、球贴着鼠标跑」，是全表手感最独特的组合之一。但寻踪符文的等级对跟随手感没有影响（LerpSpeed 被后处理覆盖），只剩「切换操控模式 + 蹭一点 Duration.AddBase」两个作用。
